# How to run

## Backend

### Prerequisites

- Go ^1.25.9

### Install dependencies

```sh
cd backend
make i
```

### Run app

```sh
cd backend
make run
```

### Testing

```sh
cd backend
make test
```

## Frontend

### Prerequisites

- NodeJS ^22.22.3 || ^24.15.0 || ^26.0.0

### Install dependencies

```sh
cd frontend
npm i
```

### Run app

```sh
cd frontend
npm run start
```

### Check Angular (TS+HTML) errors

```sh
cd frontend
npm run ngc
```
